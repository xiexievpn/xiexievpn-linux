Linux client

Build steps on Ubuntu/Debian:

1. Install dependencies:

sudo apt install python3-tk python3-venv python3-pil.imagetk

2. In the source code directory, run:

chmod +x build_linux.sh && ./build_linux.sh

The executable will be generated at: build_work/dist/xiexievpn_linux
